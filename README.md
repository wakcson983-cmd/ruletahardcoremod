# Ruleta Hardcore (Forge 1.20.1)

1. Sube TODO el contenido de esta carpeta (incluida `.github`) a tu repositorio de GitHub.
2. Ve a **Actions** > "Compilar mod" y espera a que termine (verde).
3. Entra a la ejecucion y descarga el artefacto **ruletahardcore-jar** (dentro esta el .jar).

Uso: item `Ruleta Hardcore` (pestana Herramientas). Click derecho (solo admin / op nivel 2): eliges color, titulo y texto, y das GIRAR.
Tambien funciona por comando: `/ruletahardcore <0-7> TITULO|texto`.
Debe estar instalado en el servidor y en los clientes (la animacion se ve en quien tenga el mod).
